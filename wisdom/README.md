## Sources

`sources.md` is the library. Each source is read once, summed up once, and cited by its number
(S-01, S-02, ...). It records whether we read the original or a summary of it.

## Entry format

One file per decision, `W-<nnn>-<short-name>.md`, at most about one page:

- **Date · Decided by · Status** (Proposed, Accepted, or Replaced by W-nnn)
- **Context:** what forced the decision
- **Decision:** what we do now
- **Why:** the reasoning, citing source numbers
- **Consequences:** what changes, what it costs, what follows, what is still open
